## 三条底线

1. 不直连任何 `/wapi/...` 内部接口，只用真实页面操作（ego lite）。
2. 收到 `code 37 / code 36 / code 9`、验证码、登录失效，立即停止，不重试、不重登。
3. 采集与投递、监控互斥；23:00–07:00 不运行任何自动化。

## 采集节奏

- 窗口：07:00–09:00、12:00–14:00、18:00–23:00
- 每窗口随机开始（2–14 分钟）、随机间隔（30–90 分钟）
- 早 2 次 / 午 1 次 / 晚 3 次，每次最多 30 个详情或 3 个关键词

## 投递规则

- 默认只投老板直招；非老板岗仅在明确兼职/日结/按单/完工结时可投
- 同公司不重复投（含同名、分子公司、截断名）
- 三条独立消息，间隔 2–4 秒；发送前必须过话术校验，0 违规才发

详细规则见 `BOSS风控手册.md`。
